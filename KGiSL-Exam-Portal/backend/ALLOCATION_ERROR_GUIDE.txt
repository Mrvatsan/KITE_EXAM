ERROR: "No exam halls found for 2026-01-11 (FN)"

WHY THIS HAPPENS:
-----------------
The faculty allocation system needs student exam data to know:
1. Which exam halls exist for that date
2. How many faculty members are needed (one per hall)

Your current active dataset only contains:
  ✓ 2026-01-10 (FN) - 2 halls

You tried to allocate for:
  ✗ 2026-01-11 (FN) - NOT in dataset

SOLUTION OPTIONS:
-----------------

OPTION 1: Use an Available Date
--------------------------------
1. Go to Faculty Allocation page
2. Select date: 2026-01-10
3. Select session: FN
4. BUT WAIT - This date is already LOCKED!
   
   To unlock it:
   a. You need to delete the existing confirmed allocation from database
   b. OR use a different date that's available in your dataset

OPTION 2: Upload Dataset with Tomorrow's Date (RECOMMENDED)
------------------------------------------------------------
1. Go to Admin Dashboard
2. Upload a NEW student exam dataset that includes 2026-01-11
3. Make sure the dataset is ACTIVATED (toggle to active)
4. Then go back to Faculty Allocation
5. Select date: 2026-01-11
6. The allocation will work!

OPTION 3: Unlock Today's Date (If You Want to Re-allocate)
-----------------------------------------------------------
Run this in Django shell or create a script:

    from apps.faculty.models import FacultyAllocationStatus, FacultyAllocation
    from datetime import date
    
    # Delete status for 2026-01-10
    FacultyAllocationStatus.objects.filter(
        exam_date=date(2026, 1, 10), 
        session='FN'
    ).delete()
    
    # Delete allocations for 2026-01-10
    FacultyAllocation.objects.filter(
        exam_date=date(2026, 1, 10), 
        session='FN'
    ).delete()
